SPEC REFERENCE

通过能力是参数表上根本查不到的一环，只能实测（右侧四列按 S / A / B / C 四档判读，即旗舰 / 高端 / 主流 / 入门）；测试前先关掉「禁区绕行」类设置，并记录每次失败后是自救成功、原地报错还是需要人工搬抬 —— 失败后的行为比失败率本身更能说明水平。

评分锚点

SCORE ANCHOR

所有细分项与加权总分共用同一套百分制四档标尺（S 旗舰 ≥90 / A 高端 80–89 / B 主流 65–79 / C 入门 30–64），避免跨维度松紧不一；单项与总分同尺，可互相印证。

S · 90–100 旗舰该价位段公认最好水平，无明显可挑剔项。
A · 80–89 高端优于同级多数机型，仅个别场景有妥协。
B · 65–79 主流达到同级平均水准，够用但不出彩。
C · 30–64 入门低于同级平均，过不去与卡住的区域会成为日常负担。
权重设计：垂直跨越能力 22% · 低矮与狭窄通过 18% · 边角与沿边覆盖 18% · 脱困与自救 24% · 防跌落与姿态安全 18%。脱困给到最高权重 —— 通过能力真正的分水岭不是「会不会卡」，而是「卡了以后要不要人」；垂直跨越排第二，因为门槛与地台是硬约束，过不去就是一整片区域彻底放弃；防跌落单列而不并进越障，因为它出错的后果最严重且不可逆。
