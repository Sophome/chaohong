01

洗地机测评体系目标

对用户的价值

  • 判断洗地机是不是真的比拖把好用，而不是只看参数和吸力。
  • 解释滚刷、吸力、贴边、自清洁、固液分离、续航、水箱容量、毛发处理等关键概念。
  • 帮助用户避坑：湿拖水渍残留、墙角死角、滚刷发臭、污水箱难清理、电池衰减、地毯使用限制。
  • 给出适合人群：有娃家庭、养宠家庭、老人家庭、小户型、大平层和混合地面家庭。

对内容团队的价值

  • 构建可复用的干垃圾、湿垃圾、混合垃圾、重污渍、贴边、自清洁、续航测试流程。
  • 减少“看起来干净了”“吸力很强”的纯主观表达，用标准脏污样本和水量称重说话。
  • 积累洗地机长期维护、电池衰减、异味、滚刷损耗数据，形成年度推荐和避坑内容。
  • 提升清洁家电赛道商单竞争力和客单价。

对商务合作的价值

  • 向品牌证明账号具备真实家庭地面和标准化脏污测试能力。
  • 提前明确样机、耗材（清洁液、滚刷、滤芯）、漏水、故障和结论边界。
  • 把单品测评升级为全屋清洁方案、宠物家庭专题、大促转化和年度长测合作。
洗地机测评的核心不是展示吸地面碎屑的爽感，而是回答：拖完有没有水渍、墙角干不干净、滚刷会不会发臭、污水箱是不是每次都得洗到崩溃、自清洁到底能不能洗得干净滚刷、充满电能拖多大的家。
02

测试场景搭建

场景 A：标准瓷砖 / 地板测试

  • 用途：模拟中国家庭最常见的硬质地面清洁。
  • 地面：客厅瓷砖、厨房地砖、卧室强化地板，记录材质和颜色。
  • 测试重点：水渍残留、干湿洁净度、滚刷痕迹、刮擦和地板保护。
  • 注意：不同地面颜色和材质对水渍可见度影响很大。

场景 B：干垃圾极限测试

  • 用途：测试日常灰尘、毛发、食物碎屑清除能力。
  • 脏污：面粉、米粒、瓜子壳、头发、猫砂、饼干碎。
  • 测试重点：单次通过率、吸入通道是否堵塞、干垃圾是否打湿结团。
  • 注意：干垃圾测试需要在地面完全干燥状态下进行。

场景 C：湿垃圾与混合垃圾测试

  • 用途：测试厨房及餐厅场景下液体、半流质和混合垃圾处理能力。
  • 脏污：牛奶、酱油、番茄酱、鸡蛋液、汤面、燕麦粥。
  • 测试重点：吸水性、污水箱容量、固液分离、滚刷是否会染色、污水残留。
  • 注意：混合垃圾测试后必须立即自清洁并检查异味。

场景 D：贴边与死角测试

  • 用途：测试洗地机对墙边、墙角、家具边缘的清洁能力。
  • 方法：在离墙1cm处撒面粉、米粒，检查残留。
  • 测试重点：单侧贴边、双侧贴边、低矮空间能否伸入、滚刷漏刷区域。
  • 注意：标称“0贴边”不代表所有角落都能清洁到位。

场景 E：地毯与不同地面切换测试

  • 用途：测试洗地机在地毯、短毛地毯、地垫上的清洁和干吸能力。
  • 脏污：头发、薯片渣、饼干碎、宠物粮食。
  • 测试重点：干吸模式、避免湿拖污染地毯、滚刷抬升或切换功能。
  • 注意：大部分洗地机不能用于长毛地毯，需明确说明。

场景 F：自清洁与基站体验测试

  • 用途：验证自清洁是否真的能洗干净滚刷和管道。
  • 测试：完成干湿混合重脏污清洁后，开启自清洁。
  • 检查：滚刷是否还有残留、管道是否冲洗干净、底座是否有残渣积水。
  • 注意：自清洁完成后的烘干效果、异味控制和防缠毛能力非常重要。

场景 G：续航与全屋覆盖测试

  • 用途：测试一次充电和一次加水能拖多大面积。
  • 方法：在 50㎡、100㎡、150㎡ 真实户型下连续清洁。
  • 测试重点：电池续航、水续航、自清洁次数、充电和加水时间。
  • 注意：不能只看官方宣传的“可覆盖 200㎡”，需实测。

洗地机测试项目总清单

一、干垃圾清理能力

  • 面粉：单次通过是否遗留白印、扬尘。
  • 米粒：吸入是否顺畅、是否弹飞。
  • 猫砂 / 粗颗粒：是否被滚刷打碎、残留。
  • 头发：是否缠绕滚刷、吸口是否堵塞。
  • 瓜子壳、饼干碎：大颗粒一次性吸入率。
  • 干垃圾在不同模式下的清洁效率和噪音。

二、湿垃圾与污水回收

  • 酱油 / 牛奶：残留颜色、水渍、污水回收率。
  • 番茄酱 / 鸡蛋液：黏稠液体是否清理干净。
  • 汤面 / 粥：固液混合物处理及滚刷染色。
  • 污水箱固液分离效果、一次清洁污水量。
  • 干湿混合垃圾后是否在管道内结块。
  • 吸水模式下的低噪和吸力表现。

三、贴边与死角清洁

  • 左右贴边：面粉 / 猫砂距墙 1cm 残留。
  • 前部死角：机器前端无法伸入的垂直面。
  • 家具底部：床底、沙发、电视柜下方。
  • 角落弧度：圆弧转角 vs 直角转角的清洁差异。
  • 自清洁后滚刷两端脏污是否洗净。
  • 滚筒边缘与机器外壳之间的垃圾卡入。

四、自清洁与烘干体验

  • 重脏污后自清洁：滚刷表面、清洁槽残留。
  • 管道冲洗：吸污口、污水箱接口是否冲洗到。
  • 烘干效果：滚刷潮湿度、异味、烘干时间。
  • 基站清洁：脏水、干垃圾残留和发霉风险。
  • 自清洁噪音和能耗。
  • 是否需要手动拆卸滚刷和滤芯二次清洁。

五、续航与水电管理

  • 电池续航：清档 / 高档连续工作时间。
  • 水续航：一箱净水可清洁面积。
  • 中途加水、充电、倒污水所需时间。
  • 150㎡以上大户型是否需要加水倒水。
  • 充电时间、是否可拆卸电池、备用电池成本。
  • 自动液位感应是否准确，缺水提醒是否及时。

六、毛发处理与防缠绕

  • 短发、长发、宠物毛发在滚刷上的缠绕情况。
  • 吸口、滚刷轴、污水箱过滤是否堵麻。
  • 自清洁对毛发缠绕的改善效果。
  • 随机附赠的刀片或梳齿切割器是否好用。
  • 长期使用后轴承和管道内毛发堆积。
  • 免缠绕滚刷设计的实际效果。

七、维护与使用感受

  • 机器重量、手把高度、操控力度和转向灵活度。
  • 滚刷、滤芯、清洁液的更换成本。
  • 污水箱、净水箱开盖、倒水、清洗便利性。
  • 底座摆放、充电、收纳和线缆管理。
  • 机器异味、霉菌、电池衰减、固件稳定性。
  • 保修政策、污水电机保修和售后响应。

八、噪音与安全测试

  • 标准模式、强力模式、自清洁模式噪音。
  • 污水箱水满后是否自动停机。
  • 倾斜、倾倒、平放是否漏水或造成安全隐患。
  • 充电器、适配器防水防潮等级。
  • 清洁液是否有腐蚀性或刺激性气味。
  • 儿童安全锁或防误触设计。

洗地机测评评分模型

维度 权重 核心测试 结论表达
干湿垃圾清洁力 30% 面粉、酱油、蛋液、汤面、头发、猫砂、混合垃圾。 一次性能不能拖干净，不残留污渍水痕。

毛发处理与防缠绕 8% 短发、长发、宠物毛发缠绕和清理难度。 长发家庭和养宠家庭是否友好。
维护成本与易用性 10% 滚刷、滤芯、清洁液、重量、污水箱清洁、操作手感。 买回去之后是否愿意天天用。
价格与长期成本 7% 机器价格、耗材、维修、售后。 当前价格下推荐等级。

  • 02:00 - 04:30：干垃圾一次性清理实测，展示面粉、头发、颗粒。

  • 11:00 - 13:00：续航、水箱、全屋覆盖、加水排水、噪音。
  • 13:00 - 14:30：维护、耗材成本、缺点和替代方案、最终推荐。

  • 清洁模式、滚刷类型、挡位。
  • 至少 3 个明确优点和 3 个明确缺点。
  • 水渍、异味、贴边残留和自清洁前后的证据。
  • 如有带货链接，说明可能存在佣金。

脏污后处理 立即执行自清洁，避免脏污干结，拍摄自清洁效果。 自清洁时间、烘干时间、滚刷状态。 长时间未清洁导致机器发臭、堵塞、损坏。
样品寄回 清洁滚刷、滤网、污水箱、底座，晾干后打包寄回。 寄回日期、物流单号、打包视频。 异味、霉菌、残渣引发退货纠纷。
样品留存 若样品不寄回，明确归属和后续长期使用权限。 合同或邮件确认。 利益披露不清，后续二次商单需说明。

测试红线与商单红线

核心原则：洗地机测评必须展示真实脏污、真实地面残留、真实自清洁效果。不能隐藏水渍、贴边不干净、滚刷发臭、污水箱难洗、续航虚标等真实问题，更不能因为商单把自清洁效果拍成“全新一样”。

测试红线

  • 禁止 虚构脏污量和清洁效果，或用非标准手法后期“修复”。
  • 禁止 不说明地面材质、脏污配方和清洁模式就下结论。
  • 禁止 隐藏水渍、贴边残留、滚刷染色、异味、污水箱脏污和缠绕问题。
  • 禁止 把仅适用于特别清洁场景的极限视频当作日常表现。
  • 禁止 用全新滚刷和刚出厂状态掩盖长期使用后的性能衰减。
  • 禁止 宣称“吸力永不变”“永不堵塞、永不发臭”等不科学表述。

商单红线

  • 禁止 接受“不能拍缺点、不能拍自清洁残留”的合作。
  • 禁止 接受品牌要求删除真实水渍、贴边死角、续航不足等内容。
  • 禁止 未披露商业合作、样品来源或佣金关系。
  • 禁止 在横评中恶意隐藏竞品优点或夸大推广产品数据。
  • 禁止 使用“全网第一、没有对手、彻底解放双手”等绝对表述。
  • 禁止 宣称清洁液可食用、可完全替代消毒剂等安全性误导。

可以接受的品牌修改

  • 允许 修改产品名称、型号、价格、参数、耗材价格等事实错误。
  • 允许 补充官方清洁建议、保修政策、电池保养说明。
  • 允许 修改未发布信息、保密技术细节和发布时间。
  • 允许 指出测试方法问题并要求在相同条件下复测。

不能接受的品牌修改

  • 不允许 删除真实水渍、贴边不干净、自清洁不完全、续航不足等画面和结论。
  • 不允许 要求将“不推荐”改成“推荐”。
  • 不允许 隐藏耗材成本、维护难度和设计缺陷。
  • 不允许 删除样品来源和商业合作披露。

带货转化 SOP

发布前

  • 确认主推型号、版本、基站类型和核心卖点。
  • 获取京东 / 天猫 / 抖音等链接和佣金比例。
  • 记录当前价格、历史低价、赠品和耗材礼包。
  • 准备适配清单：小户型、有娃、养宠、全屋地板等。
  • 确认是否可叠加以旧换新、平台补贴、品牌券。

发布中

  • 简介区放链接、价格参考日期和测试环境说明。
  • 评论区置顶推荐型号和适用场景。
  • 视频分段标注“贴边测试”“自清洁效果”“续航实测”。
  • 提醒价格和赠品可能变化，以下单页面为准。
  • 避免“全球最强”“绝对无残留”“永久不换耗材”等违规用语。

发布后

  • 每日更新优惠、库存、新增赠品信息。
  • 回复关于地面材质、毛发、面积、噪音等问题。
  • 统计链接点击、订单量、佣金和退货率。
  • 收集用户反馈，补充说明长期维护和耗材成本。
  • 大促后复盘转化最高的卖点和人群。

对外披露模板

视频开头 / 简介披露

本期测试产品由品牌提供样机，视频包含商业合作。我们测试使用的干湿垃圾配方、地面材质和清洁模式均在视频中说明。品牌未干预最终结论。简介购买链接可能产生佣金，但不影响推荐标准。

非商单送测披露

本期产品为品牌送测样机，未收取视频制作费用。测试过程和结论由我们独立完成。样品来源不影响我们对清洁能力、残留、自清洁和日维护体验的评价。

价格 / 效果说明

视频中价格为录制时参考价。洗地机清洁效果受地面材质、脏污种类、使用模式和维护习惯影响，实际体验可能因家庭环境不同而有差异。耗材成本和电池寿命以官方售后政策为准。

横评 / 对比披露

本次横评各机型都在相同地面、相同脏污配方和相同模式下进行，温度、湿度等环境条件已记录。结果仅代表测试条件下的表现，不同家庭可能产生差异。
