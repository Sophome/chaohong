避障实测口径

SPEC REFERENCE

避障是最容易被宣传话术糊弄的一环，以下为可当场复现的判读口径（右侧四列按 S / A / B / C 四档判读，即旗舰 / 高端 / 主流 / 入门）；测试前先跑一遍全屋建图，并在 APP 里关闭「强力模式」等会改变行进速度的选项，否则三轮数据不可比。

标准测试场建议铺开后一次跑完：数据线（散乱与盘绕各一段）、袜子、拖鞋、桌椅腿间隙、体重秤、黑色地毯、透明亚克力板、宠物粪便模拟物（可用软质黏土替代）。暗光测试需拉帘至 < 5 lux，并分别记录「激光主方案」与「视觉主方案」的降级表现 —— 多数机型在暗光下并非整体失效，而是细软物识别率先崩。制动距离要在同一档速度下测，换档后数据不可比。

评分锚点

SCORE ANCHOR

所有细分项与加权总分共用同一套百分制四档标尺（S 旗舰 ≥90 / A 高端 80–89 / B 主流 65–79 / C 入门 30–64），避免跨维度松紧不一；单项与总分同尺，可互相印证。

S · 90–100 旗舰该价位段公认最好水平，无明显可挑剔项。
A · 80–89 高端优于同级多数机型，仅个别场景有妥协。
B · 65–79 主流达到同级平均水准，够用但不出彩。
C · 30–64 入门低于同级平均，避障事故会明显拖后腿。
权重设计：感知硬件与传感系统 25% · 障碍物识别与分类 25% · 路径规划与脱困 20% · 动态避障与实时响应 15% · 场景适配与算法迭代 15%。感知与识别并列最高 —— 这两项决定「看不看得见」，绝大多数避障事故的根因都在这一层，靠算法补不回来；动态响应权重居中，因为家庭场景里移动障碍的出现频次远低于静态杂物；场景适配权重最低，但直接决定这台机器要不要人频繁设禁区，故单列保留。
