使用流程

HOW TO USE

填写评测信息

录入机型与评测人，打印时自动生成归档表头。

布设标准测试地

同一块地板上依次铺好标准粉尘、颗粒物、毛发束、地毯样块与干涸污渍，每组连测 3 次取平均。

读取结论

右侧实时汇总加权总分、等级徽章、短板项与「能否替代手动拖地」的判断。

打印归档

一键输出单色优化版 PDF / 纸质表单，含明细与结论。

评分锚点

SCORE ANCHOR

所有细分项与加权总分共用同一套百分制四档标尺（S 旗舰 ≥90 / A 高端 80–89 / B 主流 65–79 / C 入门 30–64），避免跨维度松紧不一；单项与总分同尺，可互相印证。

S · 90–100 旗舰该价位段公认最好水平，无明显可挑剔项。
A · 80–89 高端优于同级多数机型，仅个别场景有妥协。
B · 65–79 主流达到同级平均水准，够用但不出彩。
C · 30–64 入门低于同级平均，地面清洁会明显依赖人工补扫。
权重设计：吸尘与风道系统 22% · 滚刷与毛发防缠绕 20% · 地毯清洁表现 14% · 湿拖与去污能力 28% · 边角覆盖与水渍控制 16%。湿拖给到最高权重 —— 它是当下最容易「参数好看、体验拉胯」的一环，也是决定这台机器能不能替代手动拖地的唯一维度；地毯单列而不并入吸尘，因为地毯除尘率与硬质地面除尘率的排序经常相反，合并会掩盖真实差异。
