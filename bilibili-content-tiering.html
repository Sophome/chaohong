B站内容分级与排期管理方案

SABC 四级内容体系：立项按战略目标分级，指标分治。S级买记忆，A级买信任，B级买流量，C级买活跃。

01

分级原则

先定规则，再谈内容

按战略目标分级

内容等级在立项时确定，不按事后播放量划分。播放量是结果，若S级项目没爆就降级考核，团队永远不敢做重投入内容。

指标分治

每一级只考核属于自己的KPI：A级考完播率而非播放量，S级考涨粉与上榜而非完播率。用错尺子会杀死正确的事。

风险隔离

S级冲榜天然带博弈属性，失败是正常成本。季度1-2个的频率，保证单次失败不伤账号基本盘。

02

四级体系总览

不同等级，不同的钱花在不同的地方
S事件级

冲必看榜 · 破圈涨粉

季度 1-2 个，重投入。目标是被记住，买的是"记忆"。

典型形态排名赛跑可视化、观众盲测会、极限场景实测、大规模拆机对比
核心KPI播放量级 · 涨粉数 · 是否上榜
A支柱级

建立品类信任 · 养铁粉

周更或双周，中高投入。买的是"信任"。

典型形态深度横评、拆机验用料、长测记录、年度榜单
核心KPI完播率 ≥40% · 三连率 ≥8% · 收藏率 ≥3%
B流量级

搜索承接 · 长尾转化

每周 1-2 支，标准投入。买的是"流量"。

典型形态单品测评、价位段选购攻略、避坑指南（标题埋真实搜索词）
核心KPICTR ≥5% · 搜索流量占比 · 导流转化
C日常级

维持存在感 · 互动养号

高频穿插，轻投入。买的是"活跃"。

典型形态短视频、动态、直播切片、幕后花絮、评论区问答
核心KPI互动率 · 弹幕密度

05

KPI 基线与考核

每级只看自己的尺子
等级核心指标及格线优秀线考核周期
S播放量级 / 涨粉数破账号常态3倍播放破圈量级 + 单周涨粉峰值发布后7天
A完播率 / 三连率 / 收藏率40% / 6% / 2%55% / 10% / 5%发布后28天
BCTR / 搜索流量占比5% / 15%8% / 30%发布后28天（长尾看90天）
C互动率 / 弹幕密度互动率3%互动率6% + 产生可复用梗周维度汇总
诊断口径：前30秒留存断崖=开头问题；中段50%-70%流失=结构冗长；三连率高但涨粉低=内容好但缺少关注理由（补人设/系列化钩子）。
06

升降级机制

分级体系的关键闭环

B → A

某选题CTR连续3支超基线、搜索长尾持续 → 升级为固定栏目系列（如"XX价位段"栏目化）。

→

A → S

A级验证过的方法论（评测维度、数据管线、拍摄流程）沉淀入弹药库，季度S级项目直接调用。

→

C 反哺选题

评论区高频问题、弹幕争议点、动态投票结果 → 直接进入B级选题池，供需缺口分析定期校准。

07

S级冲榜SOP

每周必看：先过数据门，再过编辑门
选题过四要素：不可复制的投入 + 硬核方法 + 明确结论 + 弹幕梗点，缺一不做
周四18-20点发布，为周五18:00榜单更新留足数据窗口
标题封面：结果前置 + 具体数字 + 反常识，前30秒结论倒放
发布前2小时在线，集中回评、置顶引导弹幕钩子（"你们猜第几名"）
首日盯数据：前30秒留存、首小时CTR、弹幕密度异常点即时调整封面/简介
视频导流tool-rank数据页，承接50天决策周期的反复搜索
发布后1周加量B级内容承接新粉，避免涨粉后断供掉粉
7天后复盘：无论上榜与否，方法论沉淀回S级弹药库
