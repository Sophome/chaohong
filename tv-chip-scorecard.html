SPEC REFERENCE

SoC 与 AI 参数最容易被话术包装，以下为可当场复现的判读口径（右侧四列按 S / A / B / C 四档判读，即旗舰 / 高端 / 主流 / 入门）；测试建议固定为同一组条件（含 AV1 与 H.265 的 4K 素材、4K120 信号源、5 个常用应用冷启动记录）。

评分锚点

SCORE ANCHOR

所有细分项与加权总分共用同一套百分制四档标尺（S 旗舰 ≥90 / A 高端 80–89 / B 主流 65–79 / C 入门 30–64），避免跨维度松紧不一；单项与总分同尺，可互相印证。

S · 90–100 旗舰该价位段公认最好水平，无明显可挑剔项。
A · 80–89 高端优于同级多数机型，仅个别细节有妥协。
B · 65–79 主流达到同级平均水准，够用但不出彩。
C · 30–64 入门低于同级平均，需靠关算法或外置处理绕行。
权重设计：SoC 主控平台 24% · AI 算力与智能处理 22% · 画质引擎与算法 24% · 解码与接口带宽 16% · 扩展与长期支持 14%。SoC 与画质引擎并列最高 —— SoC 决定这台机器三年后还流不流畅，画质引擎决定它当下好不好看；解码与接口是「关键时刻会不会降级」的守门项；扩展与长期支持权重最低，但它决定前四项的能力能不能被外部设备用上，故单列保留。
