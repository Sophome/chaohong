基站实测口径

SPEC REFERENCE

基站能力只能靠长期连续使用暴露（右侧四列按 S / A / B / C 四档判读，即旗舰 / 高端 / 主流 / 入门）；建议连续作业 7 天并逐日记录人工介入次数、拖布与污水箱气味、集尘与补水中断情况 —— 单次开机测试无法反映基站的真实水平。

评分锚点

SCORE ANCHOR

所有细分项与加权总分共用同一套百分制四档标尺（S 旗舰 ≥90 / A 高端 80–89 / B 主流 65–79 / C 入门 30–64），避免跨维度松紧不一；单项与总分同尺，可互相印证。

S · 90–100 旗舰该价位段公认最好水平，无明显可挑剔项。
A · 80–89 高端优于同级多数机型，仅个别场景有妥协。
B · 65–79 主流达到同级平均水准，够用但不出彩。
C · 30–64 入门低于同级平均，基站反而会增加人工负担（洗不净、烘不干、频繁倒水）。
权重设计：洗拖布与自清洁 22% · 烘干与防霉 18% · 集尘系统 20% · 上下水与自补给 18% · 卫生与除菌除臭 22%。洗拖布与卫生并列最高 —— 这两项直接决定基站会不会变成「细菌培养皿」，也是用户投诉最集中的环节；集尘排第二，因为它是基站最早普及、用户预期最刚性的功能；上下水虽然体验增益极大，但受安装条件硬约束，故权重居中而不拔高。
