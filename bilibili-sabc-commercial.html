B站商单内容分级 SOP

以「品牌方买到了什么」为定级出发点，重新定义 S / A+ / A / B / C 五档的内容形态、交付物、制作周期与人力投入，并配套报价锚点、需求匹配与产能配比，作为商单接单与排期的执行标准。

01

分级总表

商单分级不看「内容好不好」，看品牌方买到的是什么。S = 买权威背书，A+ = 买转化，A = 买结论，B = 买曝光，C = 买排期。

03

品牌需求与档位匹配

品牌投放目标不同，考察重点与适配档位差异显著。配号应以「需求—能力」匹配为原则，而非单纯追求高档位。

投放目标核心诉求适配档位重点考察事项
曝光引爆最大化触达与声量B · C 为主，A 补强播放体量、爆款率、单条成本、数据真实性
心智种草建立品类偏好与购买意向A+ · A垂类专业度、互动质量、内容调性契合度、收藏率
效果转化可量化的成交结果A+ 主力，S 背书挂车转化率、优惠券核销、复投率、可引用 ROI 案例
权威背书信任转移与品牌形象提升S行业心智占位、测评严谨性、自研标准影响力、品牌安全
规模铺量性价比覆盖与长尾曝光C · B单条成本、内容稳定性、配合度、履约可靠性
配号原则：高等级不等于高适配。铺量预算应优先配置 B / C 形成矩阵覆盖；背书预算集中于 S；种草与转化主战场落在 A+ / A。用 S 的产能做铺量、用 C 的内容去谈背书，都是双向亏损。
04

报价锚点与承接规则

报价锚点按「交付物密度」而非「视频时长」确定。时长可短、资产可重 —— 交付物清单才是报价的真实依据。

级别价值定位典型客户场景报价锚点承接规则
S行业权威背书 + 长期资产年度框架 / 旗舰首发一次性最高，且带资产复用溢价结论不可预设；档期需提前 1 个月锁定
A+深度种草 + 强转化主推机型 / 大促单价高，ROI 可量化支撑溢价现金流主力，产能优先保障
A明确结论 + 转化中端机型 / 节点中高，按挂车链路计稳定产能，可批量排期
B曝光 + 认知新品造势中，按曝光体量计单条便宜但需量堆
C排期 + 热度活动 / 填量低，可打包计禁止用 S / A 的产能去填
三条铁律：

1. S 级不接「结论预设」的单

一旦被要求保证好评，S 就废了 —— 权威背书是长期资产，一次失信归零，且不可逆。

2. A+ 是现金流主力

产能应占商单总量的 30–40%。不要全押 S：S 一年出不了几条，押满了现金流会断。

3. C 级不是「降级」，是「排期工具」

用极低成本维持周更频率与算法活跃度。禁止用 S / A 的产能去填 C 的坑，那是净亏损。

05

说服力论据体系

说服力不等于「多做一个内容形态」。市场调研报告、行业数据这类内容属于论据层，作用是给实测结论装上权威底座，不是单独一条视频。

层级论据类型来源作用
L1 一手实测仪器读数 · 盲测 · 拆机 · 长周期耐久自建测试台与数据入库唯一别人抄不走的壁垒
L2 权威外部市场调研报告 · 行业白皮书 · 公开财报 · 供应链 / 专利信息IDC · 奥维云网 · 群智咨询 · TrendForce · 品牌年报 · RTINGS给结论背书，撑起「行业视角」
L3 用户实证评论区众测 · 粉丝返图 · 电商评价大数据 · 私域问卷自有社区与私域池证明「不是我一个人测出来」

三层论据如何嵌入视频结构

不要单开一期「市场调研报告」（无人观看）。正确做法是把调研当论据穿插：

  • 开头 30 秒 —「这个价位上季度占全市场 XX% 出货（IDC 数据）→ 所以今天我们测这 5 台」
  • 结论之前 —「从产业链看，这块面板成本约 XX → 所以它敢卖这个价」
  • 结尾收束 —「结合 XX 名粉丝反馈，翻车点集中在 XX」
一条 S 级横评的标准结构：行业格局（L2）→ 统一测试标准（方法论）→ 一手实测（L1）→ 用户实证（L3）→ 分级结论。这样交付的是行业报告级评测，而不是「我又测了一台电视」。

海外评测对标
RTINGS · Consumer Reports · AVForums（「外网怎么评」是 B站观众心智刚需）

产能配比与收入结构

分档的意义在于配比，而不只是标签。以下为建议的商单产能与收入结构，用于季度排期校准。

数量占比

S5%
A+30%
A30%
B20%
C15%
数量上以 A+ / A 为主体（合计 60%），S 控制在 5% —— S 是资产投入，不是产能投入。

收入占比

S20%
A+40%
A25%
B10%
C5%
A+ 贡献 40% 收入，是真正的现金流主力；S 以 5% 的数量贡献 20% 收入，靠的是单条溢价与资产复用。
结构健康度判断：若 A+ 收入占比低于 30%，说明价目表整体偏低或被挤在低价档；若 S 数量占比长期高于 10%，说明产能在被长周期项目拖住，现金流存在风险。
07

接单与执行清单

以下为标准动作，每单开工前逐条核对。

  • 接单前判定 档位与产能匹配：S 一季 1 条、A+ 月 2–3 条，超出即拒或改档。
  • S / A 档 必须签「结论独立性」条款：不接受预设好评，不接受删改实测数据。
  • 所有实测内容 全程留证：购买凭证、拆机过程、仪器读数画面入库归档。
  • 每条 S / A+ 视频 挂测试方法论链接（自研标准公开页），建立可复现印象。
  • 结论 前置到前 30 秒：先给「买不买」，再展开论证 —— 完播率是 B站算法第一权重。
  • 论据三层交叉：L1 实测 + L2 权威数据 + L3 用户实证，缺一层说服力就掉一档。
  • 固定 3 个栏目（S / A / B 各一），形成观众追更预期与报价锚点。
  • 每单归档 brief · 成片 · 转化数据 · 复盘结论 四件套，进商单案例库。
  • 每季度按 产能配比（S 5% / A+ 30% / A 30% / B 20% / C 15%）校准排期。
  • 数据造假、虚假宣传、重大负面舆情 → 一票否决，立即降级并冻结合作。
08

设计说明与风险提示

相对通用分级表的 5 处结构性调整

  • 插入 A+ 档 — 原 S→A 跨度太大：单品深测（10–15 天）与价位段指南（5–8 天）成本差 3 倍，混同会误判投入产出。
  • S 级加「自研度量」硬门槛 — B站数码区能立住的 S 不是「测了」，而是「别人没法反驳你的测法」。删掉「全网唯一结论」这类不成立的标准。
  • 补「留证」维度 — 购买凭证、拆机过程、仪器读数全程入镜。这不是加分项，是 S / A 的准入线，也是平台推流加分项。
  • C 级重定义为短内容 — 原「开箱图集 / 参数搬运」在 B站已被判定为低质搬运，影响推流与商单报价；健康的 C 是资讯口播 + 促销清单。
  • 显式标注周期 · 人力 · 报价锚点 — 让分档从「评价标签」变成「产能配比工具」，可直接指导排期与报价。

与账号分级体系的关系

本 SOP 解决的是「一条商单内容应该做成什么样」；账号分级（SABC 账号体系 / 商单评级体系）解决的是「一个账号值多少」。两者配合使用：账号等级决定档位天花板与报价区间，本 SOP 决定单条内容的形态与投入下限。

举例：A 级账号承接 S 级内容时，需先补齐「自研度量 + 全程留证」两项硬门槛，否则应降档为 A+ 承接 —— 形式上是 S，实质没有 S 的资产支撑，会损伤长期权威心智。

风险提示：分档的周期与人力投入基于数码 / 家电垂类中长视频制作条件测算，应随团队规模、品类复杂度与平台规则变化动态校准；报价锚点仅作内部排期与议价参考，不构成对外标准。
