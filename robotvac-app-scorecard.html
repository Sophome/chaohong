软件实测口径

SPEC REFERENCE

软件体验无法靠参数表判断，只能连续使用暴露（右侧四列按 S / A / B / C 四档判读，即旗舰 / 高端 / 主流 / 入门）；建议同一台手机、同一 Wi-Fi 环境连续使用 7 天，逐日记录掉线与重连次数、地图是否漂移、自动化场景是否按预期触发 —— 单次体验无法反映软件稳定性。

实测项S 旗舰 ≥90A 高端 80–89B 主流 65–79C 入门 30–64
首次建图耗时与完整度 ≤ 8 min 单次完成，无缺角8–15 min15–25 min 或需二次补建> 25 min 或多次失败
地图长期稳定性（7 天） 零漂移，无需重建偶有偏移可手动修正需重建 1–2 次频繁漂移或丢图重建
多楼层地图管理 支持 ≥ 3 层自动切换支持 2 层手动切换支持但需反复确认不支持多楼层
App 连接稳定性（7 天） 零掉线，秒级连接掉线 1–2 次可自愈掉线 3–5 次，需手动重连掉线频繁或无法连接
分区与选区控制粒度 任意多边形选区 + 顺序自定义房间级选区 + 顺序调整仅房间级选区仅全局或单房间
AI 识别与场景自动化 识别准确，自动化零干预识别基本准确，偶需修正识别可用但误报较多基本无识别能力
语音控制与生态接入 主流语音助手 + 本地语音 + 生态互联支持主流语音助手仅支持单一语音助手仅 App 控制
固件更新与长期维护 季度更新且持续加功能半年内有更新更新以修 bug 为主上市后基本停更
测试前先固定手机与路由器（同一频段、同一位置），否则掉线数据不可比。建图测试要从主机首次开机开始计时，中途不能人工干预；建图完成度以「实际可清扫面积 / 实测房屋面积」计算，不要只看地图外观。地图稳定性要在完成建图后连续使用 7 天，观察是否需要重建 —— 多数机型的差距不在首次建图，而在第 3 天之后。自动化场景要设一个明确的验证条件（如「离家后自动全屋清扫」），统计 7 天内的触发成功率，低于 80% 会明显影响可用性。

评分锚点

SCORE ANCHOR

所有细分项与加权总分共用同一套百分制四档标尺（S 旗舰 ≥90 / A 高端 80–89 / B 主流 65–79 / C 入门 30–64），避免跨维度松紧不一；单项与总分同尺，可互相印证。

S · 90–100 旗舰该价位段公认最好水平，无明显可挑剔项。
A · 80–89 高端优于同级多数机型，仅个别场景有妥协。
B · 65–79 主流达到同级平均水准，够用但不出彩。
C · 30–64 入门低于同级平均，软件会成为日常摩擦点（反复重连、地图要重建）。
权重设计：导航与建图 22% · 地图编辑与分区控制 18% · App 与连接稳定性 20% · 智能识别与场景自动化 22% · 语音生态与长期维护 18%。导航与自动化并列最高 —— 地图是所有软件功能的底座，建图不稳则后面全部失效；自动化决定这台机器是否需要人每天点一次开始，是「智能」与「遥控器」的分界线；连接稳定性权重居中，因为掉线可以重连而地图漂移必须重建，但频繁掉线同样会摧毁使用意愿。
