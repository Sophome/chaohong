01

行业站位模型

四级分档的本质是四种行业身份。从「排期占位」到「行业参照物」，每一级跨越的不是制作预算，而是别人对你的依赖程度：从不需要你，到必须引你。

S
行业参照物
你的数据被同行引用，你的标准被当作口径
A
品类权威
占据品类话语权，结论被消费者当购买依据
B
传播节点
信息通达、更新及时，被算法与观众同时需要
C
排期占位
维持账号活跃度，承接活动与节点
关键分野在 A 与 S 之间：A 是「你在这个品类里最有话语权」，S 是「你的话语本身就是这个品类的口径」。前者靠作品积累，后者靠标准与数据资产 —— 这也是为什么 S 级的交付物是白皮书与年度横评，而不是一条更长的视频。

04

行业影响力四层模型

判断一个账号是否够 S 级，看这四层是否咬合。四层是递进关系：没有 L1 的标准，L2 的数据就没有口径；没有 L2 的数据，L3 的引用无从发生。

L1 自有标准

方法学文档 · 测试基准 · 评分体系 · 术语定义

你定规矩 —— 把「怎么测」公开成文档，别人引用即承认你的口径。

L2 数据资产

自建规格库 · 价格监测 · 出货追踪 · 实测数据库

你有底牌 —— 持续更新 ≥ 2 个季度的数据库，是唯一别人抄不走的资产。

L3 行业引用

被媒体 / 机构 / 品牌方 / 同行引用

外面认你 —— 引用来源可核验 —— 这是 S 级的验真条件。

L4 消费者依赖

搜索先看 · 购买前必查 · 评论区自发引用

用户找你 —— 最终落到行为：观众「先收藏再购买」。

自检方法：问三个问题 —— ① 我们的测试方法有没有公开文档？② 我们的数据库连续更新了几个季度？③ 过去 12 个月，有哪个外部主体（媒体 / 机构 / 品牌 / 同行）正式引用过我们的结论？三个都答不上来，说明还没到 S 级，应先在 A 档把数据资产做厚。

品牌需求与档位匹配

品牌投放目标不同，考察重点与适配档位差异显著。最高层需求为「行业发声 / 标准共建」 —— 这是只有 S 级能承接的场景。

合作模式与报价口径

S 档走项目制与框架制，不再按「条」计价 —— 因为交付物是报告、标准与数据资产，可被品牌方二次使用与对外引用。

级别合作模式签约形态报价口径承接红线
S年度战略框架 / 联合发布白皮书 / 标准共建 / 年度横评冠名按年签约 · 三方署名（我方 + 品牌 + 协会 / 平台 / 高校）· 联合发布会年度框架费 + 成果署名权 + 数据共享 + 素材授权费结论独立性条款；白皮书方法学须经我方复核；榜单排名不可售

四条铁律

1. 权威不可售

榜单排名、白皮书结论、测试基准一律不售。售出一次，全部引用价值归零 —— 这是 S 级唯一的存在理由。

2. 标准必须公开

方法学与测试基准要公开成文档。不公开的标准只是「自家规矩」，无法被引用，也就构不成行业站位。

3. A 供养 S

A 级收入占比 55%、产能占比 50%。S 一年出不了几个，全押 S 现金流会断 —— 行业地位靠 A 级产能供养。

4. 禁止跨档承接

禁止用 S / A 的产能接 C 级活；也禁止在没有数据资产时对外宣称 S 级站位。错配一次，报价体系即崩。

08

产能配比与收入结构

行业级资产投入重、周期长，因此 S 的数量占比压得很低，产能让位给能供养现金流的 A 级。

A50%

S 仅 5%（一年 1–2 个）。用 5% 的数量撬动 28% 的收入，靠的是单项目溢价与资产复用，而不是产能堆叠。

收入占比

S28%
A55%

A 级单独贡献 55% 收入，是供养 S 级资产投入的现金流基础。
结构健康度判断：若 S 数量占比长期高于 8%，说明产能在被长周期项目拖住，现金流存在风险；若 A 级收入占比低于 45%，说明价目表整体偏低或被挤在 B 档以下，行业站位上不去。
为什么 A 级占比这么高：取消中间档后，A 级必须同时承担产出量与现金流双重职能 —— 它是唯一既有明确结论能力、又能稳定复制的档位。S 级产能供不起日常，B / C 级撑不起收入，结构上必须由 A 级做主力。
09

升级里程碑（资产积累路径）

每一级跃迁都对应一项必须新建的资产，而不是单纯的产量累积。没有资产，等级上不去；有了资产却不维护，等级会回落。

C → B  升级里程碑

  • 内容形态从「填充」升级为「服务」：固定栏目、稳定节奏
  • 信息准确率与更新时效达标
  • 建立基础测评逻辑，脱离纯搬运

B → A  升级里程碑

  • 搭建固定测试台，产出 ≥ 3 组一手实测数据
  • 形成明确结论能力（买 / 不买）
  • 跑通一次完整挂车转化链路
  • 补充产业解读能力，数据来源可追溯

A → S  升级里程碑

  • 实测样本跨 15+ 机型，形成统一测试基准，并具备年度连续性
  • 方法学文档公开发布，成为可复现的行业口径
  • 产业数据库连续更新 ≥ 2 个季度
  • 发布年度品类横评与价位段权威榜
  • 被行业协会 / 头部媒体 / 品牌方正式引用
  • 年度白皮书发布并举行发布会，发起或参与行业评测联盟
10

接单与执行清单

以下为标准动作，每单开工前逐条核对。

  • 接单前判定 行业站位与产能匹配：S 一季度 1 个、A 半月 1–2 个，超出即拒或改档。
  • S / A 项目 必须签「结论独立性」条款：不接受预设结论，不接受删改实测数据，榜单排名不可售。
  • 所有实测内容 全程留证：购买凭证、拆机过程、仪器读数画面入库归档。
  • 公开发布方法学文档（测试基准 / 评分体系 / 术语定义），挂到每条 S / A 作品的简介。
  • 建设并持续更新 产业数据库（规格库 / 价格监测 / 实测数据），更新周期不低于季度。
  • 白皮书与报告 争取三方署名（我方 + 品牌 + 协会 / 平台 / 高校实验室），提升引用权重。
  • 结论 前置到前 30 秒：先给「买不买」，再展开论证 —— 完播率是 B站算法第一权重。
  • 论据三层交叉：一手实测 + 权威外部数据 + 用户实证，缺一层说服力就掉一档。
  • 固定 3 个栏目（S / A / B 各一），形成追更预期与报价锚点。
  • 每单归档 brief · 成片 · 转化数据 · 复盘结论 四件套，进商单案例库。
  • 每季度按产能配比（S 5% / A 50% / B 28% / C 17%）校准排期。
  • 数据造假、虚假宣传、重大负面舆情 → 一票否决，立即降级并冻结合作。

结构性调整说明（相对 v1）

  • 定级依据从「内容形态」升级为「行业站位」 — v1 问「这条视频做成什么样」，本版问「你在行业里站在哪个位置」。内容形态降级为站位的表现，不再是定义本身。
  • 严格四级，取消所有「+」细分 — 原 A+（品类级 · 权威结论）职能拆解合并：品类年度横评 / 价位段权威榜 / 联合品牌报告 / 15+ 机型数据库并入 S；深度产业解读 / 粉丝众测数据集并入 A。分级只保留 S / A / B / C，判定端不再出现中间态。
  • S 级引入白皮书与标准制定 — 年度品类白皮书（60–150 页）、自研测评方法学、产业数据库、行业评测联盟、年度横评与权威榜。这是产业级交付物，不再是一条视频。
  • 新增行业影响力四层模型 — 自有标准 → 数据资产 → 行业引用 → 消费者依赖。缺任一层，S 级站位都不成立。
  • 新增「被引用」验真条件 — S 级门槛不再是自我声明，而是外部引用记录（媒体 / 机构 / 品牌方 / 同行），须可核验。
  • 新增白皮书六模块清单 — 市场规模 / 技术路线 / 产品力基准 / 价格成本 / 消费者行为 / 趋势预判，逐模块列出数据来源。
  • 升级路径压缩为三级跃迁 — C→B→A→S 每一级对应一项资产：测试台 → 统一基准（含年度连续性）→ 方法学与数据库。取消 A+ 中间站后，A→S 是最陡的一段，对应从「作品能力」到「资产能力」的跨越。
  • 合作模式与报价改为产业级口径 — 年度战略框架 / 联合发布 / 标准共建；并明确「榜单排名不可售」底线。
  • 产能配比按四级重算 — S 5% / A 50% / B 28% / C 17%。A 级承担产出量与现金流双重职能，成为绝对主力档。
风险提示：本 SOP 的周期、人力与配比基于数码 / 家电垂类「中长视频 + 自建测评体系」的生产条件测算，应随团队规模、品类复杂度与平台规则变化动态校准；报价口径仅作内部排期与议价参考，不构成对外标准。白皮书与榜单的公信力是本体系全部价值的前提 —— 一旦出现售位、改数、预设结论，整个体系即刻失效且不可逆。
